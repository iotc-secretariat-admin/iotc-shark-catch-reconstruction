# IOTC Shark Catch Reconstruction

Development of plausible catch histories for blue shark (*Prionace glauca*)
and shortfin mako (*Isurus oxyrinchus*) in the Indian Ocean.

## Species

- Blue shark (BSH)
- Shortfin mako shark (SMAK)

## Primary data sources

- IOTC retained catch (RC)
- IOTC geo-referenced catch (CA)
- IOTC geo-referenced effort (EF)
- Additional CPUE, trade, and species-composition information as available

## Reproducibility

Raw IOTC datasets are not stored in this repository because of their size
and because the underlying datasets are periodically revised.

Scripts record the source and version of each dataset used in the analysis.
